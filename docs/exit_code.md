# System Exit Code

程序退出代码一般为 3 位数字, 以 `012` 为例:
- **`0` (首位): 代表错误发生所在的系统**
    - `CODE: 1`: 用户中断 (`KeyboardInterrupt`) 等常见进程操作退出
    - `CODE: 2`: CARLA 服务端/客户端运行时的错误
    - `CODE: 3`: 基础库中出现的错误
    - `CODE: 4`: 仿真回放/数据采集等功能性模块的错误
- **`1` (次位): 代表错误发生所在的具体模块**
    - `CODE: 0`: 无具体模块或发生在主组件层面的错误
- **`2` (末位): 代表发生的具体错误**
    - `CODE: 9`: 代表由用户编写的代码逻辑出现的错误

## CODE - DESC List

| **CODE** | **DESCRIPTION** |
|----------|-----------------|
| **10X** | **用户中断 (`KeyboardInterrupt`)** |
| 100 | 在执行 `spin()`, `wait_ticks()`, `wait_seconds()`过程中发生用户中断 |
| 101 | 在服务端启动过程中发生用户中断 |
| 102 | 在等待 Actor 稳定时 `wait_stable()` 发生用户中断 |
| **21X** | **CARLA 服务端错误** |
| 211 | CARLA 服务端在启动时无法正确连接 |
| 212 | CARLA 服务端进程在运行时被检测进程发现死亡 |
| **31X** | **基础运行库::传感器相关错误** |
| 319 | 传感器类型检查失败, 调用了不匹配的方法, 如在相机中调用了被装饰器标记为 `lidar_only` 的代码 |
| **41X** | **仿真回放工具错误** |
| 419 | 记录器工作模式冲突, 如在 `RECORD` 模式下进行 `REPLAY` 操作 | 
| **42X** | **SemanticKITTI 数据集记录器错误** |
| 429 | 未定义主要的语义激光雷达或主摄像头 |
